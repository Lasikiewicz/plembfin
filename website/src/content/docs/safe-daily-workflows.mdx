## Choose the starting page

<ScreenshotFigure
  darkSrc="/assets/app-captures/dashboard-dark.png"
  lightSrc="/assets/app-captures/dashboard-light.png"
  alt="Plembfin dashboard showing the starting points for playback, continuation, and history work"

| Goal | Start here | Confirm with |
| --- | --- | --- |
| See active playback | Dashboard, Now Playing | source and progress |
| Start the next movie or released episode | Dashboard, Up Next | provider availability or Watch Now |
| Continue an incomplete title | Dashboard, Up Next | resume position |
| Save or rate a title | Discover or media details | Watchlist, Ratings, or Custom Lists |
| Mark one title watched | Movies or TV Shows, then the title action | History and Sync Activity |
| Correct a wrong title identity | Media details, Fix Match | provider details and Sync Activity |
| Repair one destination | Sync Activity, targeted retry | destination result |
| Refresh missing artwork or metadata | Settings, Metadata | title detail and Logs |
| Check a bulk operation | Sync Activity | every destination row |

## Verify a change

After a watch or manual correction:

1. Open **Sync Activity**.
2. Find the newest row for the title or operation.
3. Read each destination result separately.
4. Correct the source, match, or connection named by the reason.
5. Retry only the affected item or destination when possible.

The sidebar status is a summary. Use [Sync Activity](/docs/sync-tools/) or
[Settings → Logs](/docs/settings/#logs) when you need the evidence behind a result.
