## History

<ScreenshotFigure
  darkSrc="/assets/app-captures/history-dark.png"
  lightSrc="/assets/app-captures/history-light.png"
  alt="Plembfin Watch History page showing recent watched movie and episode records"
  caption="History is the durable event archive, with title actions and per-record sync context."
/>

History is the complete watch-event archive, newest first. Use it to answer which source
reported a watch, when it happened, or whether an item has been watched more than once.

History supports:

- **All**, **Movies**, and **TV Shows** filters;
- search by title and available history fields;
- grid, list, and card layouts;
- adjustable poster size;
- links to media details;
- sync-status indicators;
- poster three-dot actions; and
- the watch-date editor and history debug view where available.

Same-event delivery echoes are collapsed so propagation does not count as several views.
Genuine later rewatches remain separate watch dates. For cleanup tools, see
[Database repairs](/docs/settings/#database-repairs).

## Global Search

<ScreenshotFigure
  darkSrc="/assets/app-captures/global-search-dark.png"
  lightSrc="/assets/app-captures/global-search-light.png"
  alt="Plembfin global search showing matching local titles and provider results"
  caption="Global Search finds local titles, people, and provider matches before opening the selected result."
/>

Global Search searches local movies and shows, people, TMDB, and TheTVDB. Local library
results are prioritised and marked as already in the archive.

Use the filters for **All**, **Movies**, **Shows**, or **People**. A person result opens a
person page; a movie or show result opens the standard detail view.

Search is for finding and exploring a title. Use the local title's actions when you need
to change canonical watch state.
