The Changelog is the in-app release history. It shows the release running on this instance,
newer published releases, and the Alpha channel builds available for the current release
cycle.

## Open the in-app Changelog

1. Click the version button in the bottom-left corner of the Plembfin sidebar, such as
   **v1.2.0**.
2. Plembfin opens **Settings → Changelog**.
3. Use **Stable releases** for published releases or **Alpha builds** for pre-release work.
4. Select **Check for updates** when you want to refresh the release data.

The version button is a navigation control, not an upgrade action. Reading Alpha builds or
checking for updates never changes the installed version.

The public site also has a [Changelog](/changelog/) for release notes without opening a
running instance. Use [About](/docs/settings/about/) when you only need to confirm which
version is installed.
